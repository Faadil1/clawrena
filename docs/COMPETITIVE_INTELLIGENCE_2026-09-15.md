## New category thesis

**Alpha Scout is an Evidence Underwriter / Execution Authority for autonomous capital.**

Other systems discover, analyze, recommend or trade. Alpha Scout decides whether the record has earned authority to continue and preserves the refusal when it has not.

Canonical chain:

`signal → evidence record → authority verdict → value movement or refusal → proof receipt`

The reusable primitive is the **Evidence Passport**:

- policy version
- deterministic replay key
- authority state
- evidence freshness expiry
- observed unknowns/reasons
- counterfactual conditions for reconsideration
- later execution proof when it actually exists

## Competitive white space

High-confidence white space from this scan:

1. **Cross-agent execution authority** — a reusable gate that sits between signal generation and fund movement.
2. **Replayable policy receipts** — show not only the decision, but which versioned policy created it.
3. **Counterfactual refusal** — a rejection states what evidence must change before reconsideration.
4. **Machine-readable authority contract** — other agents can inspect Alpha Scout's semantics before integrating it.
5. **Hermes/ClawPump community skill** — package the authority model as sponsor-native reusable tooling instead of a product-only feature.

## What we should not copy

- Do not copy SelfMade's hardware/body flywheel.
- Do not copy HyperBull's staking/yield/buyback economics.
- Do not add a virtual world because Agent Heights made one memorable.
- Do not invent a holder revenue share to imitate fee leaders.
- Do not turn every refusal into an AI explanation layer; the deterministic evidence boundary remains the authority.

## Remaining competitive weaknesses

These are not solved by P11 code alone:

- Alpha Scout is not currently visible as a tokenized Clawrena entry on the official analytics leaderboard.
- no realised on-chain performance exists yet
- no meaningful Clawrena fee history exists yet
- no public attention/distribution proof has been captured
- no live $ANSEM use case has been demonstrated
- the custom Evidence Authority skill is packaged locally but still needs to be imported into a real ClawPump/Hermes agent and ideally contributed upstream
- the canonical live negative-path receipt still needs to be captured

These gaps have higher judge impact than another cosmetic UI pass.
