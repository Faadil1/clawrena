## Competitive pressure

The space is not empty. The official analytics page showed **154 tokenized Clawrena entries** and substantial aggregate Clawrena volume at this snapshot. Generic “AI trader on Solana” is therefore not a defensible differentiator.

The public Anima description is especially adjacent: it advertises Solana-token research, risk flags, wallet reading and swap pricing that the user signs. That means Alpha Scout must not position itself merely as “agent + risk flags + swap.”

## Collision classes

| Collision | Why generic positioning loses | Alpha Scout distance |
|---|---|---|
| autonomous trader/sniper | crowded, easy to wrap existing tools | structured evidence + refusal receipts + execution authority |
| risk dashboard | explains but does not control value movement | risk evidence can veto provider execution |
| wallet copilot / swap assistant | adjacent to Anima and other agent surfaces | fresh stored receipt + provider preflight + explicit PREPARE/EXECUTE boundary |
| memecoin scanner | commodity discovery | verified Pump create parsing + investigation + proof chain |
| “AI alpha” marketing | difficult to substantiate | no performance claim until realised evidence exists |

## Agent Advantage test

The agent layer earns its place only if at least one is true in the final product:

1. it continuously executes a multi-tool objective loop a static UI cannot;
2. it adapts investigation steps based on what evidence is missing;
3. it coordinates reusable ClawPump/Hermes skills;
4. it generates/requests evidence but cannot override deterministic capital authority;
5. it produces an auditable state transition from observation to action/refusal.

If none is demonstrated, downgrade the narrative. Do not claim “AI” as a differentiator by itself.

## Winning distance

Canonical thesis:

> **The agent is not trusted because it is intelligent. It is trusted only to the extent that its evidence and execution authority can be verified.**

This is the distance to protect during future feature/UI work.
